```py
import customtkinter as ctk


### 全域設定
ctk.set_appearance_mode("dark") # 設定外觀模式，可使用 "System"、"Dark"、"Light"


### 建立主視窗
window = ctk.CTk() # 建立 CustomTkinter 主視窗
window.title("我的第一個視窗") # 設定視窗標題
window.geometry("400x800") # 設定視窗大小，寬 400、高 800，單位為像素


### 啟動視窗
window.mainloop() # 啟動事件迴圈，讓視窗持續顯示並等待使用者操作
```
