# 首頁

嗨，我是維誠。匍匐於程式設計、人工智慧與教育的小蝦米。

畢業於國立成功大學工程科學研究所，大學就讀國立臺東大學資訊工程學系。一路走來，我參與過資訊教育、AI 應用、物聯網、後端開發等不同領域，也累積了不少教學經驗。

這幾年我碰過蠻多東西，像是資訊教育、AI 應用、物聯網、後端開發……也累積了不少教學經驗。我一直覺得，技術最酷的地方不是程式寫得多厲害，而是真的能解決生活中的問題。所以我特別喜歡把 AI、電腦視覺、自動化工具跟日常結合，做出那種「看起來不複雜、用起來卻很實用」的東西。

平常主要用 Python 開發，OpenCV、PyTorch、YOLO、MediaPipe、DeepFace、Streamlit 這些工具都算熟悉。也做過影像辨識、車牌辨識、人臉辨識、姿態估計、天氣儀表板……各種有趣的 AI 小專案。
除了寫程式，我也很喜歡跟大家分享這些技術。不管是大學生、社區大學的學員，還是完全沒碰過程式的初學者，我都希望能用簡單好懂的方式，讓大家發現：「原來 AI 沒有想像中那麼遙遠。」

這個網站就是我一路走來的紀錄，裡面有專案、教學內容、學習筆記跟一些開發心得。希望這些東西能幫到同樣對程式設計或 AI 有興趣的人。

如果對我的作品有興趣，或是想交流、合作，都非常歡迎跟我聊聊！
