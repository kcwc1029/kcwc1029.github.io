# 快速生成圖像：用Gemini建立第一張作品

很多人認為 AI 生圖就是：

```
輸入 Prompt => 產生圖片
```

但真正的流程其實是：

```
Idea => Design Brief => 選擇風格 => 描述畫面 => AI生成 => 判斷 => 修正 => 完成作品
```

AI 並不是替你設計。而是把你的設計轉成圖片。因此，圖片品質通常取決於：

- 想法有沒有清楚
- 描述有沒有完整
- 是否知道如何修正

### Problem.

請畫一張圖片：

> 一間咖啡店

不要急著輸入 AI。請先回答：

- 主題？
- 場景？
- 氣氛？
- 風格？

> 很多新手會一直想： 我要一次畫成功。
> 其實不用。第一張圖只有兩個目的：
> ✓ 驗證方向
> ✓ 找出問題
> 所以第一次生成，只要回答：我是不是走在正確方向？而不是好不好看？

### Problem.

假設我要設計科技咖啡品牌。第一次 Prompt：

```text
一家現代科技感咖啡店，
大片落地窗，
深色木質，
夜晚，
暖黃燈光，
安靜，
電影感，
高細節，
真實攝影。
```

> 不用一次加入很多描述。先看方向。

## 圖像風格的重要性

很多人不知道：

- Prompt 決定內容。
- 風格決定畫面。

例如：「一位女孩坐在咖啡店。」

如果換不同風格：

- 電影風格 -> 像電影劇照
- 油畫 -> 像美術館作品
- 動漫 -> 日系插畫
- 寫實攝影 -> 像 Sony 相機拍的照片

## 四種最常用風格

| 風格類型                       | 適合用途                                 | 常用關鍵字 (Prompt)                                                                                                    | 特色                                                           |
| ------------------------------ | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **寫實攝影 (Photorealistic)**  | 商品攝影、品牌形象、商業廣告、人像攝影   | `photorealistic`<br>`realistic`<br>`cinematic`<br>`professional photography`<br>`DSLR`<br>`85mm lens`<br>`high detail` | 接近真實照片，光影自然、細節豐富，適合商業應用與品牌展示。     |
| **插畫設計 (Illustration)**    | 社群貼文、海報設計、品牌角色、書籍封面   | `illustration`<br>`flat design`<br>`minimal`<br>`vector`<br>`watercolor`                                               | 偏向設計與藝術風格，不追求真實感，可塑性高，容易建立品牌特色。 |
| **幻想世界 (Fantasy)**         | RPG 遊戲、奇幻小說、世界觀設定、角色設計 | `fantasy`<br>`magic`<br>`steampunk`<br>`cyberpunk`<br>`dark fantasy`                                                   | 強調世界觀、故事性與想像力，適合創意、科幻或奇幻主題。         |
| **氛圍類 (Mood / Atmosphere)** | 情境插圖、品牌形象、電影海報、社群視覺   | `peaceful`<br>`cozy`<br>`warm`<br>`nostalgic`<br>`lonely`<br>`dreamy`                                                  | 著重畫面傳達的情緒與氛圍，而非物件本身，能大幅影響作品的感受。 |

## 如何寫 Prompt？

很多人會寫：

```
科技感
```

AI：

???

因為沒有畫面。

真正要寫的是：

```
主體

+

場景

+

風格

```

例如：

```
一位工程師

+

坐在深夜辦公室

+

電影感
```

就會容易很多。

## 圖片不好，不代表 Prompt 很差

圖片不好。通常只有三種原因。

問題一：主體不清楚。例如：

```
科技感空間 -> AI不知道重點。

改成：
一間現代辦公室，中央是一張長桌。
```

問題二：場景太少。例如：

```
咖啡店 -> 對AI來說，任何咖啡店都有可能。

改成：
東京街角，
玻璃落地窗，
雨天，
夜晚。
```

問題三：風格衝突。例如：

```
可愛 + 高端品牌 + 寫實 + 卡通 -> AI不知道該相信哪個。
```

### Problem. 打造科技咖啡品牌主視覺

請設計一張品牌首頁 Hero Banner。需求：

- 品牌：Prompt Coffee
- 對象：工程師、設計師
- 氣氛：沉穩、高級
- 色彩：黑色、深灰、暖黃
- 時間：夜晚
- 用途：品牌官網首頁

### Problem. 同一 Prompt，不同風格

Prompt：

> 一位女孩坐在窗邊閱讀。

請分別生成：

- 寫實攝影
- 油畫
- 水彩
- 日系動漫

比較四張圖的差異，觀察風格如何改變畫面的表現。
