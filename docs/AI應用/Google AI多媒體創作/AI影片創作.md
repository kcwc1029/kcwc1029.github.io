# AI 影片創作核心：以 Kling 為主

> 可直接授課版｜建議 180 分鐘，可拆成兩堂 90 分鐘課程  
> 原教材以 Google Veo 為示範工具；本版保留原教材全部觀念與實例，實作流程及 Prompt 改以 Kling 為主。

---

## 一、版本與工具說明

本課教授的是「AI 影片思維」，不是只記某個版本的按鈕位置。

截至 2026 年，Kling 已推出 3.0 系列，官方資料顯示其支援文字、圖片、音訊與影片的多模態輸入輸出，並提供多鏡頭敘事、元素參考、主體一致性與原生影音生成等能力。不同帳號、方案、地區與模型版本可能只開放其中部分功能。

因此，實際操作前應先確認目前介面可用的：

- Text-to-Video／文字生影片。
- Image-to-Video／圖片生影片。
- Multi-Shot／多鏡頭。
- Elements／元素或主體參考。
- Start Frame／End Frame。
- Motion、Camera 或運鏡控制。
- Native Audio／原生音訊。
- Extend／延伸。
- Video Editing／影片編修。

若某項功能未開放，仍可使用「短片段生成＋剪輯軟體組合」完成同樣的敘事目標。

### 本課核心句

> 圖片呈現一個瞬間；影片設計一段時間。

> 影片不是動態圖片，而是一段被設計的時間體驗。

> 生成工具負責產生素材；創作者負責設計起點、變化、結果與節奏。

# 第一單元　影片的本質：為什麼「影片＝敘事」

## 1-1 講師導入話術

【講師可直接說】

前面我們已經可以用 AI 發想、建立圖像、控制角色與風格，也能設計網頁版型。但當我們希望內容讓人停下來、產生情緒或留下記憶，只有漂亮畫面還不夠。

影片真正的力量，不只在畫面好不好看，而在畫面之間如何連接。即使是相同場景，只要畫面依序發生變化，觀眾就會開始理解：發生了什麼、為什麼發生，以及最後變成什麼。

因此，影片的重點不在單一畫面，而在：

- 畫面如何開始。
- 畫面如何轉變。
- 畫面如何結束。

這三件事會形成傳達意圖與引導理解的能力。

## 1-2 圖片與影片的差別

### 圖片：呈現一個瞬間

- 聚焦單一畫面。
- 強調構圖與細節。
- 傳達「這一刻是什麼」。

例如：

- 一位人物坐在咖啡廳工作的畫面。
- 一張未來科技場景設計圖。

重點是畫面完整性。

### 影片：呈現一段過程

- 有時間推進。
- 有變化發生。
- 有前後關係。

同樣是咖啡廳工作，影片可以呈現：

1. 人物打開筆電。
2. 開始操作。
3. 螢幕逐漸出現內容。
4. 鏡頭靠近成果。

重點是過程與變化。

| 項目 | 圖片     | 影片     |
| ---- | -------- | -------- |
| 時間 | 單一瞬間 | 持續變化 |
| 重點 | 畫面品質 | 過程設計 |
| 表現 | 靜態     | 動態     |
| 目的 | 呈現     | 引導理解 |

## 1-3 為什麼這很重要

若用圖片思維製作影片，常出現：

- 畫面漂亮，但沒有變化。
- 缺乏節奏。
- 觀眾很快失去興趣。

改用影片思維，則會問：

- 畫面從哪裡開始？
- 中間發生什麼變化？
- 最後要留下什麼結果？

### 小結

> 圖片描述畫面；影片設計畫面如何改變。

# 第二單元　影片的三個核心元素

無論影片長短與內容多複雜，都能拆成：

> 起點（Start）→ 變化（Change）→ 結果（End）

## 2-1 起點：畫面從哪裡開始

作用：讓觀眾快速進入情境。

通常回答：

- 現在是什麼情況？
- 主角在哪裡？
- 當下有什麼目標或問題？

例如：

- 一位創作者坐在桌前。
- 一個安靜的工作畫面。
- 一個尚未啟動的裝置。

重點不是複雜，而是清楚。

## 2-2 變化：畫面發生什麼改變

沒有變化，就沒有影片。變化可能來自：

- 動作：人物操作、移動、抬頭。
- 物件：螢幕亮起、介面更新、產品展開。
- 環境：光線改變、煙霧流動、粒子出現。
- 鏡頭：推進、拉遠、平移、環繞。
- 聲音：環境音、提示音、旁白或音樂進入。

例如：

- 手開始操作電腦。
- 螢幕亮起並顯示內容。
- 鏡頭慢慢靠近主體。

這一段決定影片是否吸引人。

## 2-3 結果：最後留下什麼畫面

作用：讓觀眾記住這段影片。

常見結果：

- 完成的設計畫面。
- 穩定運作的系統。
- 安靜專注的工作氛圍。
- 產品完成變化後的 Hero Shot。
- 主角理解、驚喜或滿意的表情。

重點是收束與印象。

## 2-4 三者如何組合

- 起點建立情境。
- 變化推動過程。
- 結果留下印象。

缺少起點：看不懂在做什麼。  
缺少變化：像靜態圖片。  
缺少結果：沒有記憶點。

### 課堂練習：三句話腳本

題目：「AI 幫助學生整理學習資料」。

請只用三句話完成：

```text
起點：
變化：
結果：
```

參考答案：

```text
起點：學生面對散亂筆記與多個檔案，神情困擾。
變化：AI 介面逐步整理內容，將資料分類成摘要、重點與待辦。
結果：桌面變得整齊，學生看著清楚的學習地圖露出安心微笑。
```

# 第三單元　從「描述」轉向「設計」

## 3-1 常見操作誤區

許多人使用 AI 影片工具時，只會描述一個畫面：

```text
一位女性在辦公室使用電腦，畫面很漂亮，光線柔和。
```

這段文字只有靜態資訊，沒有：

- 動作。
- 變化。
- 鏡頭。
- 結果。

生成結果容易像一張會呼吸的圖片。

## 3-2 正確的影片思維

```text
一位女性在咖啡廳中開始操作筆電，
手部移動，螢幕逐漸亮起並生成設計內容，
鏡頭從中景緩慢推近至螢幕與人物表情，
窗外暖光逐漸增強，最後停在完成的設計畫面。
```

關鍵差異：有過程。

## 3-3 AI 時代的優勢

傳統影片通常需要：

- 分鏡。
- 拍攝。
- 演員與場景。
- 剪輯與後製。

AI 工具能依照設計好的過程，快速產生視覺素材。創作重點因此由技術執行，部分轉向：

- 流程設計。
- 動態設計。
- 鏡頭設計。
- 節奏設計。
- 結果篩選與組合。

> 創作者不是要求 AI「幫我做影片」，而是告訴 AI「畫面要如何變化」。

# 第四單元　Kling 模型概念：能力與限制

## 4-1 先理解工具邏輯

原教材以 Veo 說明「它不是剪輯工具，而是生成工具」。套用到 Kling，核心仍成立：

> Kling 的主要角色是生成與延伸動態內容；剪接、字幕、精準節奏與正式交付，通常仍需剪輯軟體完成。

## 4-2 Kling 的核心能力

### Text-to-Video

用文字描述：

- 場景。
- 角色。
- 動作。
- 環境。
- 鏡頭。
- 氛圍。
- 聲音（若目前模型支援原生影音）。

### Image-to-Video

將靜態圖片延伸為動態內容，可：

- 保持既有構圖與風格。
- 延續角色與品牌視覺。
- 加入人物、物件、環境與鏡頭微動態。

### Camera Movement

常見描述：

- Push in／Dolly in：鏡頭推進。
- Pull back／Dolly out：鏡頭拉遠。
- Pan left／right：水平搖攝。
- Tracking shot：跟拍。
- Orbit：環繞。
- Tilt up／down：上下搖攝。
- Static camera：固定鏡頭。

### Motion Generation

可演算：

- 人物動作。
- 物件變化。
- 光線流動。
- 環境變化。
- 畫面節奏。

### Multi-Shot 與元素參考

若帳號支援 Kling 3.0：

- 可啟用 Multi-Shot 讓模型規劃鏡頭。
- 可使用 Custom Multi-Shot 指定鏡頭與時間。
- 可用 Elements 或參考圖鎖定人物、物件及場景。
- 可綁定主體，提高跨鏡頭一致性。

### 原生影音

若使用支援原生影音的模型，可同時描述：

- 對白。
- 旁白。
- 環境音。
- 音效。
- 音樂氣氛。

若目前版本不支援，先生成無聲影片，再後製配音。

## 4-3 Kling 的限制

### 細節控制有限

可能出現：

- 手部動作不自然。
- 物件變形。
- 小元素不穩定。
- 複雜操作步驟錯誤。

策略：

- 減少同時發生的動作。
- 讓一個鏡頭只有一個主要動作。
- 避免要求精準操作複雜設備。

### 角色一致性仍需管理

長影片或多鏡頭可能出現：

- 臉部漂移。
- 服裝改變。
- 髮型或年齡改變。
- 氣質偏移。

策略：

- 優先使用 Image-to-Video。
- 使用 Elements／主體參考。
- 使用相同角色基準圖。
- 拆成短片段後剪輯。

### 文字容易變形

即使新模型強化文字能力，仍需人工確認：

- 中文字是否正確。
- Logo 是否變形。
- 螢幕 UI 是否在動態中漂移。

正式字幕、價格、日期與品牌標誌建議後製加入。

### 長影片連貫性限制

時間越長，越容易：

- 劇情不連續。
- 畫面風格漂移。
- 動作不合理。

最佳策略：

> 拆成多個短鏡頭，再進行剪輯組合。

### 精準控制不是百分之百

AI 生成擅長創造與變化，不等於傳統 3D 或實拍的逐格控制。Prompt 應使用「引導」，而不是期待每個細節完全服從。

# 第五單元　Kling 最佳使用情境

## 5-1 短影片內容

適合：

- 有動態變化的內容。
- 具有節奏感的短影片。
- 單一情境。
- 明確動作。
- 社群短影音、廣告素材與品牌氛圍片。

## 5-2 品牌形象影片

適合建立：

- 品牌氛圍。
- 視覺風格。
- 情緒感受。

例如：

- 科技感品牌。
- 生活風格品牌。
- 創作者個人品牌。

關鍵在強調感覺，而不是塞入大量細節。

## 5-3 社群吸睛內容

影片任務是讓人停下來，可快速建立：

- 視覺吸引畫面。
- 有動態變化的內容。
- 有節奏感的短影片。

適合 Instagram、短影音平台與行銷素材。

## 5-4 情境與概念呈現

例如：

- AI 工具運作。
- 未來科技場景。
- 工作流程想像。

Kling 可用畫面讓觀眾看懂概念，不只用文字說明。

## 5-5 不適合的使用情境

- 需要極高角色一致性的長篇劇情。
- 要求逐步精準操作的教學影片。
- 每個細節都必須完全指定的內容。
- 必須正確顯示大量文字、表格或程式碼的畫面。
- 需要法律、醫療或新聞證據價值的真實紀錄。

判斷原則：

> 氛圍導向適合；高度精準導向應搭配實拍、動畫、螢幕錄影或傳統後製。

# 第六單元　Text-to-Video：從文字生成影片

## 6-1 核心觀念

Text-to-Video 的關鍵不是寫得很長，而是讓描述帶有：

- 時間感。
- 變化性。
- 清楚的主次關係。

## 6-2 五大 Prompt 結構

```text
【主題 Subject】誰／在哪裡？
【動作 Action】正在發生什麼變化？
【環境 Environment】有哪些場景元素與光線？
【鏡頭 Camera】觀眾如何觀看？
【氛圍 Mood】希望傳達什麼感受？
```

Kling 補強欄位：

```text
【時間流程】起點 → 變化 → 結果
【節奏】緩慢／中速／快速
【一致性】角色、服裝、場景不可改變
【聲音】旁白、環境音、音效、音樂（若支援）
【限制】不要剪接／不要文字／不要多餘人物／不要變形
【輸出】比例、用途、時長
```

### 通用 Prompt 模板

```text
【主題】__________
【起點】影片開始時__________
【主要動作】接著__________
【環境變化】同時__________
【鏡頭】鏡頭__________
【結果】最後停在__________
【風格與氛圍】__________
【一致性】保持__________不變
【聲音】__________
【限制】不要__________
【輸出】__________比例，用於__________
```

# 第七單元　原教材 Text-to-Video 實例

## 7-1 實例一：工作情境（基礎入門）

### 設計拆解

- 主題：女性創作者在咖啡廳。
- 動作：操作筆電與繪圖板。
- 環境：桌上有咖啡與書本。
- 鏡頭：慢慢推進。
- 氛圍：溫暖、安靜、專注。

### 原教材 Prompt

```text
一位女性創作者坐在咖啡廳中使用筆電與繪圖板工作，
手部自然操作，畫面中的螢幕微微發光，
桌上擺有咖啡與書本，窗外光線灑入，
鏡頭從側面緩慢推進，
整體氛圍溫暖、安靜且專注，帶有柔和電影感。
```

### Kling 補強版

```text
單一連續鏡頭，8 秒，16:9。
起點：一位戴眼鏡的女性創作者坐在溫暖咖啡廳的木桌前，
桌上有筆電、繪圖板、咖啡與兩本書，午後陽光從窗外灑入。
變化：她先用右手操作繪圖板，左手輕觸筆電觸控板；
螢幕亮度微微提升，咖啡熱氣緩慢上升，背景客人只有自然細微動作。
鏡頭：中側面中景，極慢速推進，始終聚焦人物與工作區。
結果：最後停在她專注查看完成設計、露出淡淡滿意表情的畫面。
半寫實電影攝影，暖色柔光，安靜、專注、自然。
保持人物臉部、服裝、桌面配置與場景一致。
不要切鏡、不要新增人物、不要文字、不要誇張手勢、不要物件變形。
```

觀察重點：

- 有明確動作。
- 有鏡頭變化。
- 有環境微動態。
- 只設計一個主要過程。

## 7-2 實例二：科技情境（風格強化）

### 設計拆解

- 主題：AI 創作者在未來實驗室。
- 動作：操作全息介面。
- 環境：科技設備與數據流。
- 鏡頭：環繞移動。
- 氛圍：科技感、未來感。

### 原教材 Prompt

```text
一位創作者站在未來 AI 實驗室中，
手部操作全息投影介面，數據與光線在空中流動，
背景為高科技設備與藍紫色光影，
鏡頭緩慢環繞主體移動，
整體氛圍具有強烈科技感與未來感，光線帶有霓虹效果。
```

### Kling 補強版

```text
單一電影感鏡頭，8 秒，16:9。
起點：一位短髮創作者站在藍紫色未來 AI 實驗室中央，
面前是半透明全息介面，周圍有伺服器、資料光流與神經網路圖形。
變化：創作者用雙手緩慢控制介面，

藍紫科技色、霓虹輪廓光、未來感、專業、電影質感。

不要快速旋轉、不要爆炸、不要額外角色、不要文字、不要手指變形。
```

觀察重點：

- 動作更明確。
- 環境得到強化。
- 鏡頭增加動態。

# 第八單元　影片範本：先選方向，再寫 Prompt

原教材以 Gemini 影片範本示範「先定義創作方向」。改用 Kling 時，可以把範本理解成風格與敘事起點，而不是固定效果。

## 8-1 五種範本類型

### 場景／世界觀型

例：文明、宇宙、星塵、電玩遊戲。

特點：

- 建立完整環境。
- 強調氛圍與空間。

適合故事開場、場景建立與世界觀內容。

### 角色／主題聚焦型

例：華麗風、情誼、動作英雄。

特點：

- 聚焦人物。
- 強調角色氣質。

適合人物介紹、品牌形象與角色影片。

### 風格／視覺強化型

例：金屬、賽博龐克、JellyToon。

特點：

- 風格鮮明。
- 視覺衝擊強。

適合吸睛內容、創意影片與風格展示。

### 物件／主題聚焦型

例：ASMR 蘋果、爆米花、鉤針編織。

特點：

- 聚焦單一物件。
- 強調細節與感官。

適合商品展示、短影音與感官內容。

### 動態／行動型

例：競賽跑道、動作英雄。

特點：

- 強調速度與動作。
- 節奏明確。

適合運動、動作與刺激型影片。

## 8-2 初學者要不要選範本

- 可以不選，先讓模型自行推測，熟悉基本能力。
- 若選擇，先用穩定且容易理解的方向。

建議：

- 場景清楚：文明。
- 人物穩定：華麗風。
- 主體明確：產品／物件聚焦。

進階後，才主動使用風格範本控制影片方向。

### 小結

> 影片範本不是附加效果，而是影片方向的起點。

> 用文字設計一段可以被觀看的過程。

# 第十單元　Image-to-Video：從圖片延伸影片

## 10-1 為什麼重要

Text-to-Video 每次從零開始，結果較難預測。Image-to-Video 則由已確定的畫面出發。

### Text-to-Video

- 每次重新生成。
- 結果較難預測。
- 角色與風格容易變動。

### Image-to-Video

- 以既有圖像為基礎。
- 結果較穩定。
- 風格自然延續。
- 角色與品牌更容易維持。

核心差異：

> 從零開始，與從成果延伸。

## 10-2 維持風格一致

若已建立：

- 固定色彩。
- 穩定風格。
- 一致構圖。

Image-to-Video 可以延續既有的視覺資產，降低：

- 色調偏移。
- 風格改變。
- 畫面不一致。

## 10-3 保持角色一致

適用：

- 固定女性創作者。
- AI 助手。
- 品牌代表人物。

常見問題：

- 臉部改變。
- 造型不一致。
- 氣質偏移。

建議：

- 使用清楚的角色基準圖。
- 使用 Elements／Bind Subject（若支援）。
- Prompt 重複寫明不可改變的特徵。
- 避免一次加入太多劇烈動作。

## 10-4 提升生成穩定度

Image-to-Video 的特性：

- 起點固定。
- 變化可控。
- 結果較可預期。

好處：

- 減少反覆生成。
- 提高成功率。
- 節省時間。

## 10-5 完整創作流程

原教材流程：

```text
Gemini → 發想
Nano Banana Pro → 圖像
Veo → 動態延伸
```

改為 Kling 主流程：

```text
文字模型／腳本工具 → 發想與分鏡
圖像生成或攝影素材 → 建立角色、場景與起始畫面
Kling Image-to-Video → 動態延伸
剪輯軟體 → 組合、字幕、音訊與輸出
```

若使用 Kling 3.0 多模態能力，可在 Kling 中直接加入圖片、影片、聲音或元素參考，但正式成品仍應經人工剪輯與品管。

# 第十一單元　讓圖片產生自然動態

## 11-1 核心原則

很多人一次修改太多：

- 改場景。
- 改角色。
- 改風格。
- 加複雜動作。

結果會失去一致性。Image-to-Video 的核心原則：

> 不改內容，只加入動態。

把它理解成：

> 在一張完成的畫面上，加入時間與變化。

## 11-2 是否還需要選擇風格

通常不需重新選風格，前提是原圖已有明確：

- 色彩風格。
- 光線氛圍。
- 視覺語言。

Prompt 應說：

```text
延續原圖風格，不重新設計角色、場景或配色。
```

## 11-3 動態優先順序

1. 動作：手部、表情、物件。
2. 光線：亮度、流動、反射。
3. 鏡頭：推進、平移、環繞。

一次只加入少量、清楚的變化。

觀察重點：

- 角色不變。
- 風格不變。
- 場景完全延續。

原始圖像內容：

- 短髮女性角色，戴眼鏡。
- 藍紫科技感外套。
- 位於未來 AI 實驗室。

```text
保持同一角色的臉部、眼鏡、短髮、藍紫外套、
實驗室結構、介面位置、配色與半寫實科技插畫風格一致。
不要切鏡、不要出現新角色、不要劇烈閃光、
不要爆炸、不要改變臉部、不要生成文字或 logo。
```

觀察重點：

- 角色不變。
- 風格不變。
- 場景不變。
- 動態不只人物，而是整個系統在運作。

## 12-3 關鍵技巧

Image-to-Video 成功關鍵：

- 變化要小，但清楚。
- 微動作大於一次改變整個世界。

- 不改角色。
- 不改風格。

優先加入：

- 動作。
- 光線。
- 鏡頭。

> 讓畫面慢慢動，而不是重新做。

# 第十三單元　從畫面生成到影片故事

前面的能力包括：

- 建立創作藍圖。
- 產出穩定圖像。
- 建立視覺系統。
- 建立版型。
- 讓圖片產生動態。

但故事還需要節奏。

## 13-1 本章建立的三個核心能力

### 影片思維：從畫面到過程

- 圖片是瞬間。
- 影片是過程。
- 基本結構是起點、變化、結果。

### Kling 操作能力：從生成到控制

- Text-to-Video。
- Image-to-Video。
- 鏡頭與動態。
- 多鏡頭與元素參考（若支援）。

操作方式應由：

```text
嘗試生成
↓
篩選基礎
↓
設計變化
↓
引導結果
```

### 動態設計：從畫面到節奏

- 用動作建立變化。
- 用鏡頭建立節奏。
- 用光線與環境強化氛圍。
- Image-to-Video 不改內容，只增加動態。

## 13-2 Kling 的真正角色

Kling 的本質不是完整剪輯工具，而是情境、鏡頭與素材生成工具。

它的價值：

- 讓畫面產生變化。
- 讓內容更具吸引力。
- 讓觀眾願意停下來。

真正的影片故事仍需要：

- 分鏡排序。
- 節奏控制。
- 剪接。
- 聲音。
- 字幕。
- 開場與結尾。

# 第十四單元　Kling 多鏡頭故事設計

## 14-1 四鏡頭短片結構

建議每支短片先做四個鏡頭：

1. 建立場景。
2. 主角開始行動。
3. 發生明確變化。
4. 結果與收束。

### 範例：AI 創作者完成作品

| 鏡頭 | 畫面            | 動作                   | 鏡頭     |
| ---- | --------------- | ---------------------- | -------- |
| 1    | 咖啡廳工作桌    | 主角坐下打開筆電       | 緩慢橫移 |
| 2    | 主角開始創作    | 手操作繪圖板           | 中景推進 |
| 3    | AI 介面生成內容 | 光線與圖像形成         | 螢幕特寫 |
| 4    | 完成作品        | 主角微笑，畫面停在成果 | 緩慢拉遠 |

若使用 Kling Multi-Shot：

```text
多鏡頭短片，總長 12～15 秒，四個連續鏡頭。
鏡頭一：……
鏡頭二：……
鏡頭三：……
鏡頭四：……
所有鏡頭保持同一女性角色、服裝、咖啡廳布局與暖色電影風格。
```

若沒有 Multi-Shot：

- 分別生成四個短片。
- 每段使用同一角色參考圖。
- 在剪輯軟體中組合。

## 14-2 節奏原則

- 每鏡頭只負責一件事。
- 開場先讓觀眾看懂。
- 中段一定要有變化。
- 結尾需要明確畫面。
- 不要每一秒都有新特效。

# 第十五單元　新增課堂題目與參考答案

## Problem 1：找出圖片思維

```text
一台高級咖啡機放在廚房，畫面漂亮，晨光柔和。
```

問題：缺少哪些影片元素？

參考答案：缺少動作、環境變化、鏡頭與結果。

### 參考改寫

```text
晨光照進安靜廚房，一台高級咖啡機靜置在檯面上。
按鍵亮起，機器開始研磨咖啡豆，細小蒸氣緩慢升起，
深色咖啡流入白色杯中。
鏡頭由咖啡機全景緩慢推進至杯口，
最後停在咖啡表面的細緻油脂與晨光反射。
```

## Problem 2：一次動太多

Prompt 同時要求人物奔跑、換裝、場景爆炸、鏡頭旋轉、天氣改變。應如何改善？

參考答案：

- 拆成多個鏡頭。
- 每鏡頭只保留一個主要動作。
- 角色換裝與場景改變分開處理。
- 使用剪輯建立節奏。

## Problem 3：Image-to-Video 角色漂移

角色臉部與外套在生成後改變。請寫補救 Prompt。

```text
以原始圖片為唯一角色基準。
保持人物臉部輪廓、眼鏡、短髮、膚色與藍紫外套完全一致。
只增加右手在繪圖板上小幅度移動與咖啡熱氣，
其他角色、服裝、場景、色彩、構圖與光線不變。
不要切鏡、不要轉身、不要改變表情、不要重新設計人物。
```

## Problem 4：設計起點、變化與結果

題目：「AI 幫助小店完成商品廣告」。

參考答案：

```text
起點：店主面對空白廣告版面與商品照片，神情困擾。
變化：AI 介面整理照片、色彩與文案區，廣告版面逐步形成。
結果：完成的商品廣告出現在螢幕，店主露出安心笑容。
```

## Problem 5：選 Text-to-Video 或 Image-to-Video

1. 完全沒有素材，想探索未來城市。
2. 已有固定品牌角色，要做系列影片。
3. 要讓既有產品主視覺產生微動態。
4. 想快速探索三種故事方向。

參考答案：1 Text-to-Video；2 Image-to-Video＋Elements；3 Image-to-Video；4 Text-to-Video 或範本探索。

## 講師收束話術

【講師可直接說】

AI 影片的品質，不只取決於畫面精緻度，而在於變化是否清楚。

當你使用 Kling 時，不要只描述畫面裡有什麼，而要設計：它從哪裡開始、中間發生什麼、最後留下什麼。

Text-to-Video 適合從零探索；Image-to-Video 適合從既有成果延伸。角色與品牌內容應優先使用圖片與元素參考；長故事則拆成短鏡頭，再透過剪輯組合。

真正重要的不是一次生成得多漂亮，而是能否有意識地控制敘事、動作、鏡頭、節奏與一致性。

> Kling 讓畫面動起來；創作者讓變化成為故事。
