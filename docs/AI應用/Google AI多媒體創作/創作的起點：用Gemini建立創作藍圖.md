# 創作的起點：用Gemini建立創作藍圖

很多人第一次接觸 AI 都是這樣：

- 今天叫它畫圖。
- 明天寫文章。
- 後天做 Logo。

結果每次都很好。但是全部放在一起...，卻不像同一個作品。

## 真正缺少的是什麼？

很多人以為 Prompt 不夠強。其實真正缺的是三件事。

第一，主題 (Idea)：回答「我要做什麼？」。如果沒有主題。今天畫咖啡。明天畫汽車。後天畫動漫。作品一定會散掉。

第二，風格 (Direction)：回答「我要給人什麼感覺？」。例如高級、科技、療癒、日系、商業、童趣、成熟。

第三，結構 (Structure)：回答「我要如何呈現？」。例如一篇貼文，從標題、副標題、故事，再到CTA。沒有結構。內容永遠寫不完。

## AI 不只是生成工具

很多人把 Gemini 當 ChatGPT。想到什麼就問。其實更好的方式是把 Gemini 當企劃。例如：

```
不要直接問：「幫我畫一家咖啡店。」

而是先問：
我要打造一家高端精品咖啡品牌。

請協助我完成：

1. 品牌定位
2. 目標客群
3. 核心理念
4. 品牌故事
```

AI 就會開始思考。而不是直接畫圖。

### Problem. 練習 Prompt

```
你是一位品牌企劃。

請協助我規劃一個品牌。

請包含：

品牌名稱

品牌定位

目標客群

核心理念

品牌價值

品牌故事

一句品牌標語
```

## Design Brief 是什麼？

很多設計公司真正開始畫圖之前。都會先做一份東西。叫做Design Brief(創作藍圖)。例如：

```
品牌：Prompt Coffee
定位：高端科技咖啡品牌
客群：工程師、設計師、AI 創作者
核心訊息：喝的不只是咖啡。而是靈感。
品牌標語：Fuel Your Mind.
```

完成這份 Brief。AI 才知道要往哪裡走。

### Problem. 用 Gemini 建立 Design Brief

我現在要建立一家甜點店，請你幫我生成該店的廣告圖，不要直接生成圖片。先完成 Brief。

```
請扮演品牌企劃。

我要建立一個品牌。

請依序詢問我：

1. 品牌名稱
2. 品牌定位
3. 客群
4. 核心理念
5. 競爭優勢
6. 品牌故事
7. 品牌個性

最後整理成 Design Brief。
```

## 建立文案結構

有了品牌。下一步就是建立內容。例如：Instagram，可以使用：

- 主標題
- 副標
- 故事
- 產品特色
- CTA

### Problem. 用 Gemini 建立 Design Brief

現在要建立一家早餐店，請建立：

- 品牌 Brief
- Logo 概念
- IG 文案

## 建立視覺風格

很多人只寫：「畫一杯咖啡。」

AI 根本不知道你的風格。應該把風格拆開。例如：

```
色彩：黑色、白色、奶油色、莫蘭迪、霓虹
光線：自然光、逆光、電影光、工作室、柔光
氛圍：科技感、療癒、孤獨、商業、高端、極簡
構圖：Close-up、Wide Shot、Top View、Macro、Rule of Thirds
```

### Problem. 用 Gemini 建立

請使用 Gemini，建立一家 AI 健身品牌。請依序完成：

- 品牌名稱

- 目標客群
- 品牌故事
- 品牌 Logo 概念
- 色彩規範

- 廣告海報
