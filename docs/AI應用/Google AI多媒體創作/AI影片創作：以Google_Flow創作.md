# AI 影片創作：以 Google Flow 創作

## 影片的三個核心元素

再短的影片，也可以拆成：

1. **起點（Start）**：建立情境，讓觀眾知道現在在哪裡、誰在畫面中。
2. **變化（Change）**：人物、物件、光線、環境或鏡頭發生改變。
3. **結果（End）**：留下完成狀態、明確畫面、情緒或訊息。

```text
例如「創作者在咖啡廳使用 AI」：
- 起點：女性創作者坐在桌前，筆電尚未操作。
- 變化：她開始操作，螢幕逐漸出現設計內容，鏡頭緩慢靠近。
- 結果：畫面停在完成的設計成果，她露出理解與滿意的表情。
沒有起點，觀眾不知道發生什麼；沒有變化，影片只是動態桌布；沒有結果，影片沒有記憶點。
```

## 從「描述畫面」轉為「設計變化」

錯誤寫法：「一位女性在咖啡廳使用電腦，畫面很漂亮，光線柔和。」

這是圖片描述，沒有明確動態。

改善寫法：「一位女性創作者坐在咖啡廳中開始操作筆電，手部自然移動，螢幕內容逐漸亮起，窗外柔光緩慢變化，鏡頭從側面慢慢推近，最後停在她專注而安心的表情。」

差別不在形容詞更多，而在於加入：

- 可見的動作
- 可理解的變化
- 鏡頭節奏
- 最終畫面

## Text-to-Video——從文字生成影片

### 五大 Prompt 結構

建議固定使用：

```text
> **主題 Subject + 動作 Action + 環境 Environment + 鏡頭 Camera + 氛圍 Mood**

1. **主題**：誰、什麼物件、在哪種情境。
2. **動作**：正在發生什麼變化。
3. **環境**：場景、背景元素、光線。
4. **鏡頭**：遠近、角度、移動方式。
5. **氛圍**：觀眾應感受到什麼。
```

```text
### 通用模板：
主題：[]
動作：先[]，接著[]，最後[]。
環境：[]，光線[]。
鏡頭：[]景，鏡頭[]。
氛圍與風格：[]。
畫面比例：[]，片長：[]秒。
避免：多餘人物、突變、畫面文字、角色外觀改變。
```

## Image-to-Video——從既有畫面延伸動態

Text-to-Video 是「從零開始」，Image-to-Video 是「從既有視覺基準延伸」。後者通常更適合品牌與系列內容，因為：

- 起點已固定。
- 角色外觀較容易延續。
- 色彩、風格與構圖較穩定。
- 結果更容易預測。

核心原則：「不改內容，只加入動態」。先加入三類變化：

1. 動作：手部、表情、物件。
2. 光線：亮度、反射、流動。
3. 鏡頭：推進、平移、環繞。
4. 最後才考慮大型場景轉換。

常見錯誤是同時改場景、角色與風格，結果失去一致性。

### Problem. 人物情境延伸

```text
原始畫面：
- 長髮女性創作者，戴眼鏡。
- 黑色牛仔外套。
- 坐在咖啡廳木質環境中。
- 桌上有咖啡、筆電與繪圖板。
```

```text
Prompt：
生成8秒影片
畫面中的長髮戴眼鏡女性創作者，黑色牛仔外套專注工作，
右手使用繪圖板設計，左手在筆電鍵盤上輕微操作，
繪圖板上的設計內容逐漸完成，
桌上咖啡冒出微微熱氣，背景人物有細微動作，
窗邊燈光自然流動，鏡頭緩慢向前推進並聚焦主角，
保持角色外觀、藍紫科技色調與木質咖啡廳風格完全一致。
```

觀察：

- 角色不變。
- 場景完整延續。
- 只增加手部、螢幕、蒸氣、光線與鏡頭的微動態。

### 起始影格與結束影格

若當下模型支援起訖影格，可指定：

- 起始畫面：故事從哪裡出發。
- 結束畫面：故事要抵達哪裡。

```text
例如：
- 起始影格：咖啡杯放在桌上，沒有品牌標誌。
- 結束影格：鏡頭拉近，杯身出現品牌視覺，蒸氣形成柔和圖案。

# 中間的動態仍需描述，否則模型只知道兩端，不知道過程應如何發生。
```

## 多段影片生成、串接與一致性

每一段分鏡都應該有一個明確任務：

- 開場：建立場景與氛圍。
- 發展：推進動作或資訊。
- 轉折：產生變化或衝突。
- 結尾：收束情緒與訊息。

每段不是一張畫面，而是一個功能。

### 建立片段的三個原則

1. **單一重點**：每段只負責一個核心動作或情境。
2. **可延續性**：能自然接到下一段。
3. **視覺一致性**：不同段落像同一支影片。

```text
### Flow 中的實作邏輯

1. 建立或開啟專案。
2. 建立角色、場景與風格素材。
3. 將素材拖入 Prompt，或指定起始／結束影格。
4. 生成第一段可用片段。
5. 以最後影格或延長功能建立下一段。
6. 使用不同版本比較動作、鏡頭與情緒。
7. 將片段按敘事順序整理。
8. 必要時移除不需要的物件、調整局部內容或鏡頭。
9. 輸出後再進行字幕、品牌標誌、音樂與精準剪輯。

# 小技巧：先排順序，再修細節。順序錯誤時，再精緻的畫面也救不了故事。
# 不同模型功能可能不同；生成前先查看目前模型支援的片長、參考素材、延長、音訊與編修能力。
```

## 完整案例——貓娘小姐姐

主題設定：貓娘小姐姐的一天

```text
# 角色設定
白色貓耳與柔順長髮，真人版
穿著簡約可愛的居家服。
金色眼睛，表情溫柔。
尾巴會隨情緒自然擺動。
活潑但有點害羞。
```

```text=
### 角色設計 Prompt
請幫我設計一位可愛的貓娘女孩，
```

## Prompt 工具箱

### 單段影片模板

```text
在【場景】中，【角色／物件】先【起始狀態】，
接著【主要動作與變化】，
周圍【環境或光線變化】，
鏡頭以【鏡頭方式】呈現，
最後停在【結果畫面】，
整體為【氛圍／風格】。
```

### 圖片延伸模板

```text
以這張圖片為視覺基準。
保持【角色外觀、服裝、場景、構圖、色彩】不變，
只增加【主體動作】、【物件微動】、【光線變化】，
鏡頭【推進／平移／環繞】，
動作自然且幅度小，
不要新增人物，不要改變角色，不要更換場景與風格。
```

### 跨片段延續模板

```text
延續上一個場景與最後動作。
保持同一角色的【外觀特徵】、同一【服裝】、
同一【色彩、光線、影像風格】。
角色接著【下一個主要動作】，
鏡頭【運動方式】，
本段任務是【建立／推進／轉折／收束】。
```

### 產生變體模板

```text
保留角色、動作、場景與構圖不變，
只提供 3 個【光線／鏡頭／節奏】版本：
版本 A：__________。
版本 B：__________。
版本 C：__________。
```

### 負面限制建議

```text
避免多餘人物、避免手部扭曲、避免服裝改變、
避免突然切換場景、避免過快鏡頭、避免畫面文字、
避免角色臉部漂移、避免同時發生過多事件。
```
