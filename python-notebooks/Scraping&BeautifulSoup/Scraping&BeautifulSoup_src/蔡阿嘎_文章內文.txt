標題：蔡阿嘎

蔡阿嘎 （1984年7月21日—），本名 蔡緯嘉 ，是 臺灣 嘉義市 出身的 部落客 、 網絡名人 及歌手。2008年起，在部落格上傳以愛臺灣為主題的時事議題影片、搞笑影片。2017年11月，與其他四位喜愛音樂的 YouTuber 組成樂團「 七月半 」並擔任主唱 [ 3 ] 。

2014年達成 Facebook 百萬粉絲、YouTube頻道百萬訂閱、YouTube頻道點閱人次破億等紀錄。截至2019年3月16日，頻道訂閱數超過200萬，為台灣第三個訂閱人數超過200萬的 YouTube 頻道 [ 4 ] 。2019年6月20日，蔡阿嘎第二頻道「蔡阿嘎Life」訂閱人數破100萬，為臺灣第一位擁有兩個百萬訂閱頻道的YouTuber。2020年2月21日，獲 中華民國教育部 頒發「109年本土語言傑出貢獻獎」 [ 5 ] 。

蔡阿嘎出生於 嘉義市 ，父母於其一歲時離婚，九歲時父親因車禍去世，之後由家人扶養長大 [ 6 ] 。大學畢業後，為維繫與同學情誼開始拍攝影片並上傳至 YouTube 頻道 [ 7 ] 。2008年因 2008年夏季奧運棒球最終資格排名賽 相關影片（包含焚燒Roots衣物以表抵制加拿大產品），以及2010年因「黑襪事件」相關抵制韓國商品影片，在網路上引發流傳。上述內容原為個人情緒抒發影片，後於球迷間擴散。自2009年起，未再針對棒球國際賽事拍攝抵制影片，創作主題轉向臺灣社會時事、旅遊、臺語教學及搞笑內容 [ 8 ] 。

2009年通過專技高考社會工作師考試。2010年起開始參與座談與演講活動 [ 9 ] [ 10 ] [ 11 ] 。2011年至2015年間擔任 東吳大學 社會工作學系第六、七屆系友會會長。2011年至2012年間曾任 國家政策研究基金會 研究助理 [ 12 ] 。自2011年2月起，陸續拍攝臺灣各縣市旅遊景點及小吃等旅遊短片。 [ 8 ] [ 13 ] 亦以一般市民視角製作多支社會時事影片，包括「整個城市。都是蔡阿嘎的靠杯館」系列，內容涵蓋男女交往、青年就業、薪資、物價上漲及政治貪腐等議題；並於「10秒影展」及MV翻拍等作品中延伸相關時事內容。 [ 14 ] [ 15 ] [ 16 ] [ 17 ] 同時製作「每日一臺詞－臺語教學」及「嘎名人，學臺語」系列，邀請各界人士共同學習臺語 [ 18 ] 。2013年成立個人媒體工作室 大頭佛娛樂有限公司 。2013年10月，其拍攝的《半澤直樹》相關影片在日本引發關注，並促使日本 TBS 來臺採訪。 [ 19 ]

2014年，其「破解網路流言」系列中「泡麵加布丁」實驗影片登上《洛杉磯時報》報導； [ 20 ] 2017年愚人節上傳「運動飲料可為手機充電」影片（《嘎奇麥唬爛#31》），引發媒體報導及網路討論，並造成部分觀眾誤信內容。 [ 21 ] [ 22 ] 2017年7月24日，推出臺語單元「嘎名人 尬臺語」系列。 [ 23 ] [ 24 ] [ 18 ] 2018年7月6日至15日舉辦「蔡阿嘎10週年夏日感謝祭回饋鄉親週年限定展」。 [ 25 ] [ 26 ] 2019年3月，於 中華民國總統府 接受時任 總統 蔡英文 授旗。同年9月7日代表臺灣於美國職棒大聯盟國家聯盟紐約大都會隊「臺灣日」活動中擔任開球嘉賓。 [ 27 ] [ 28 ] [ 29 ] 6月28日，推出單元「酸民代言人」，蒐集並回應網路酸民留言。 [ 30 ] [ 30 ] [ 31 ] [ 32 ] 2019年10月，依據Social Lab社群實驗室調查「公益議題網路聲量：名人有效擴展公益討論熱度」，其於公益議題聲量排行居首。 [ 33 ] 同年，YouTube公布台灣年度影片排行榜，其頻道內容於熱門創作者美食影片排行第1名、跨界合作影片第6名及熱門影片第7名。 [ 34 ]

2020年3月3日，蔡阿嘎騎乘機車載孕妻停等紅燈時，遭一名黑衣男子持鈍器攻擊，造成其右手肘及膝蓋挫傷，其妻亦受傷並出現宮縮與腹痛等症狀，兩人送醫後均無大礙 [ 35 ] [ 36 ] 。同年3月5日，警方於新北市林口區逮捕兩名嫌犯 [ 37 ] 。2020年獲教育部頒發本土語言傑出貢獻獎，並參與Google臺灣節目《Google愛台玩》。 [ 38 ] 2022年7月21日，成立社會福利協會。 [ 39 ] 2022年7月23日成立第六頻道「蔡阿嘎543」，上線10天達10萬訂閱；其同名Podcast亦登上Apple Podcasts與Spotify熱門排行榜第一名。2023年12月1日成立第七頻道「大頭佛工作室」，以員工為主要創作主體，截至2024年8月訂閱數約20萬。

2023年6月2日，因上傳影片〈日本5家超難吃的連鎖地雷店〉，片中使用「爆幹難吃」、「直接罵沒關係啊，這邊的人聽不懂」等語句，並以批評語氣評論多家餐廳，引發爭議。外界亦質疑其內容包含先入為主評論、於店內佔用公共空間拍攝、多人共食單一餐點及喧嘩等行為，認為有欠妥當及不尊重店家與其他顧客。影片其後下架，蔡阿嘎並發布中、日文道歉聲明。惟事件仍延燒，並登上日本 富士電視台 等媒體報導。 [ 40 ] [ 41 ] [ 42 ] [ 43 ]

2024年6月6日，蔡阿嘎工作室發布聲明，宣布解聘資深員工林沛蓁（暱稱蘿拉），指其涉及不法行為，導致公司損失。隨後，相關指控內容陸續曝光，包括涉嫌私吞收入、擅自使用公司名義及工作場域內的爭議行為。蔡阿嘎與團隊透過多部影片進一步說明事件過程，並著手進行法律行動。

2024年11月，蔡阿嘎向法院聲請扣押蘿拉名下財產，過程中警方於蘿拉住所發現毒品，相關案件進一步進入司法程序。蘿拉於道歉聲明中提出對公司多項指控，引發社會關注，而蔡阿嘎則透過律師駁斥並強調將追究法律責任。事件的進展及雙方的公開聲明，持續引發外界對職場管理、法律糾紛及網紅產業的多方探討。

2026年6月，蔡阿嘎於日本街頭邀請 似顏繪 （ 日语 ： 似顔絵 ） 畫家 （ 日语 ： 似顔絵師 ） 為其子繪製肖像，並於 Instagram 限時動態中，將畫作與以 AI生成圖像 進行對比，並發起網路投票比較，引發「AI與畫家作品比較」相關討論，部分網友認為此舉涉及對街頭畫家的不尊重，事件隨後引起爭議，並遭日本媒體報導。 [ 44 ] 其後，蔡阿嘎發布影片回應，表示相關限時動態並無不尊重畫家之意，認為外界部分解讀有所誤會。 [ 45 ] [ 46 ] [ 47 ]

事件延燒期間，有報導指出其透過社群建立粉絲群組，號召支持者協助在網路上澄清與回應輿論。 [ 48 ] 後續亦衍生民眾網路連署抵制與其合作品牌之行動。 [ 49 ] 該行動後經蔡阿嘎道歉後宣告終止。 [ 50 ] [ 51 ] 6月29日，蔡阿嘎再度透過社群發布二度道歉，坦承自己在事件中的言行有許多需要反省之處。 [ 52 ] [ 53 ]

2016年12月31日，與 李佩潔 （二伯）結婚 [ 54 ] 。

2018年7月21日，長子 蔡桃貴 （乳名）出生 [ 55 ] 。2020年4月1日，次子 蔡波能 （乳名）出生 [ 56 ] 。
