    快速生成圖像：用Gemini建立第一張作品¶

    很多人認為 AI 生圖就是：

    輸入 Prompt => 產生圖片

    但真正的流程其實是：

    Idea => Design Brief => 選擇風格 => 描述畫面 => AI生成 => 判斷 => 修正 => 完成作品

    AI 並不是替你設計。而是把你的設計轉成圖片。因此，圖片品質通常取決於：

    • 想法有沒有清楚
    • 描述有沒有完整
    • 是否知道如何修正

    Problem.¶

    請畫一張圖片：

    一間咖啡店

    不要急著輸入 AI。請先回答：

    • 主題？
    • 場景？
    • 氣氛？
    • 風格？

    很多新手會一直想： 我要一次畫成功。 其實不用。第一張圖只有兩個目的： ✓ 驗證方向 ✓ 找出問題 所以第一次生成，只要回答：我是不是走在正確方向？而不是好不好看？

    Problem.¶

    假設我要設計科技咖啡品牌。第一次 Prompt：

    一家現代科技感咖啡店，
大片落地窗，
深色木質，
夜晚，
暖黃燈光，
安靜，
電影感，
高細節，
真實攝影。

    不用一次加入很多描述。先看方向。

    圖像風格的重要性¶

    很多人不知道：

    • Prompt 決定內容。
    • 風格決定畫面。

    例如：「一位女孩坐在咖啡店。」

    如果換不同風格：

    • 電影風格 -> 像電影劇照
    • 油畫 -> 像美術館作品
    • 動漫 -> 日系插畫
    • 寫實攝影 -> 像 Sony 相機拍的照片

    如何寫 Prompt？¶

    很多人會寫：

    科技感

    AI：

    ???

    因為沒有畫面。

    真正要寫的是：

    主體

+

場景

+

風格

    例如：

    一位工程師

+

坐在深夜辦公室

+

電影感

    就會容易很多。

    Prompt 公式¶

    主體

+

場景

+

風格

+

光線

+

鏡頭

+

細節

    例如：

    一位工程師坐在木質辦公桌前，
桌上有 MacBook、
筆記本、
咖啡，
夜晚，
窗外城市燈光，
電影感，
暖黃光，
85mm Lens，
Ultra Realistic，
High Detail。

    圖片不好，不代表 Prompt 很差¶

    圖片不好。通常只有三種原因。

    問題一：主體不清楚。例如：

    科技感空間 -> AI不知道重點。

改成：
一間現代辦公室，中央是一張長桌。

    問題二：場景太少。例如：

    咖啡店 -> 對AI來說，任何咖啡店都有可能。

改成：
東京街角，
玻璃落地窗，
雨天，
夜晚。

    問題三：風格衝突。例如：

    可愛 + 高端品牌 + 寫實 + 卡通 -> AI不知道該相信哪個。

    Problem. 打造科技咖啡品牌主視覺¶

    請設計一張品牌首頁 Hero Banner。需求：

    • 品牌：Prompt Coffee
    • 對象：工程師、設計師
    • 氣氛：沉穩、高級
    • 色彩：黑色、深灰、暖黃
    • 時間：夜晚
    • 用途：品牌官網首頁

    Problem. 同一 Prompt，不同風格¶

    Prompt：

    一位女孩坐在窗邊閱讀。

    請分別生成：

    • 寫實攝影
    • 油畫
    • 水彩
    • 日系動漫

    比較四張圖的差異，觀察風格如何改變畫面的表現。

    Problem. 圖片診斷¶

    請生成一張圖片後，用下表檢查：

    項目 評分(1~5) 問題 修改方式
    主體是否清楚
    場景是否完整
    光線是否符合
    色彩是否一致
    氛圍是否符合
    品牌風格是否一致
