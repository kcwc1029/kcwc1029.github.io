科赫雪花是由三條科赫曲線（Koch Curve）組成的。所以，我們首先需要了解科赫曲線的生成規則。
科赫曲線是一種遞迴（Recursive）圖案，其生成規則非常簡單：

- 初始狀態（0 階）：一條直線段。
- 迭代規則：將每一條直線段分割成四個長度為原線段三分之一的小線段。
    - 將中間三分之一的線段移除。
    - 在這個空缺處，向外凸出一個等邊三角形。

重複這個步驟，你就能得到更高階的科赫曲線。當這個過程無限次地進行下去時，最終形成的曲線就是科赫曲線。
