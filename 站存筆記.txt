## 更新教材到網站
cd D:\github\web-mkdocs\mydocs
啟動虛擬環境(web-mkdocs)
git push
mkdocs gh-deploy

## 網站本地瀏覽
mkdocs serve

## 放圖片
```html=
<!-- 兩張 -->
<div style="display: flex; flex-wrap: wrap; gap: 20px;">
    <img
        src="images/photo1.jpg"
        alt="第一張圖片"
        style="width: calc(50% - 10px); height: auto; object-fit: cover;">
    <img
        src="images/photo1.jpg"
        alt="第一張圖片"
        style="width: calc(50% - 10px); height: auto; object-fit: cover;">
</div>
```

```html=
<!-- 三張 -->
<div style="display: flex; flex-wrap: wrap; gap: 20px;">
    <img
        src="images/photo1.jpg"
        alt="第一張圖片"
        style="width: calc((100% - 40px) / 3); height: auto; object-fit: cover;">

    <img
        src="images/photo2.jpg"
        alt="第二張圖片"
        style="width: calc((100% - 40px) / 3); height: auto; object-fit: cover;">

    <img
        src="images/photo3.jpg"
        alt="第三張圖片"
        style="width: calc((100% - 40px) / 3); height: auto; object-fit: cover;">
</div>
```

```html
<!-- 播放影片 -->
<div class="video-wrapper">
    <iframe
        src="https://drive.google.com/file/d/drive的ID/preview"
        allow="autoplay"
        allowfullscreen>
    </iframe>
</div>
```

```html
<!-- 左邊圖片 + 右邊影片 -->
<div style="display: flex; flex-wrap: wrap; gap: 20px; align-items: flex-start;">

    <!-- 左邊圖片 -->
    <img
        src="images/photo1.jpg"
        alt="圖片"
        style="
            flex: 1;
            min-width: 300px;
            width: 100%;
            height: auto;
            object-fit: cover;
        ">

    <!-- 右邊影片 -->
    <div
        style="
            flex: 1;
            min-width: 300px;
            position: relative;
            padding-top: 56.25%;
        ">
        <iframe
            src="https://drive.google.com/file/d/你的DriveID/preview"
            allow="autoplay"
            allowfullscreen
            style="
                position: absolute;
                top: 0;
                left: 0;
                width: 100%;
                height: 100%;
                border: 0;
            ">
        </iframe>
    </div>
</div>
```

```html
<!-- 播放音樂 -->
<video 
    src="https://drive.google.com/file/d/你的DriveID/preview" 
    controls 
    style="max-width: 200px; width: 100%; height: auto; display: block; margin: 0 auto;">
您的瀏覽器不支援 HTML5 影片播放。
</video>
```
